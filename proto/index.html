품번 및 원소재 사용량 관리

업체별 기준 파트단가와 품번별 원소재 사용량을 독립적으로 관리합니다.

원소재 열은 자유롭게 추가할 수 있습니다. 환율은 kg 입력 대상이 아니므로 소재 중량 열에 넣지 말고 계약 조건 메모로 별도 관리하세요. CSV 업로드는 엑셀에서 ‘CSV UTF-8’ 형식으로 저장한 파일을 지원합니다.

품번 데이터

※ 빈 셀은 미입력, 0은 사용량 0kg으로 구분하여 저장합니다. 품번별 소재 데이터는 별도 행으로 저장됩니다.

Index 데이터 관리

구매기획팀에서 배포한 원소재 Index 데이터를 등록하고 확인합니다.

현재 시제품은 구매기획팀에서 제공하는 가로형 Excel(.xlsx) 파일을 업로드합니다. 첫 번째 Sheet에서 원소재 이름·규격·기준·단위·출처 및 날짜별 가격을 읽어 기준지표 목록으로 등록합니다. CSV 업로드도 지원합니다.

원소재 이름규격기준단위출처원본 파일 / Sheet가격 데이터 수관리

※ 삭제 시 해당 지표와 업체 계약정보의 지표 연결만 해제됩니다. 업체·품번·원소재 사용량은 유지됩니다. 삭제된 지표는 재업로드해야 합니다.

연동제 계산

업체 계약 조건과 품번별 데이터를 기준으로 계산 검토를 준비합니다.

중요: 실제 계약 수식이 등록·검증되지 않은 상태에서 임의의 연동액을 산출하지 않습니다. 이 시제품은 계산 대상 선택과 데이터 완전성 점검까지만 수행합니다.
